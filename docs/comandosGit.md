## Estamos aprendiendo a usar git, esto es una gia rapida para cuando sea necesario

git branch -> para revisar en que rama se esta

git switch -> para cambiar de rama

git switch -c nuevaRama -> para cambiar y agregar nueva rama 


git fetch origin  - para descargar los cambios (trae la información nueva sin tocar tu código)
git merge origin/main -> para  actualizar todo de main y subir a la rama personal (une lo descargado con tu rama actual)


git pull -> es la combinacion de fetch y merge (une y descarga puede ser mas caotico)


git status -> para comprobar el estatus 

git add . -> para agregar cambios 

git commit -m "" -> para comentar cambios

git push -> para subir (solamente en la rama en la que se esta)

git push origin nombre-de-tu-rama:main -> para subir desde la rama personal a main (cuidado con esto)
